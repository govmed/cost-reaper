cost-reaper — Documentation

Technology Project Cost Estimator. Consistent, auditable cost estimates from a governed rate card and AWS / GCP / Azure compute pricing — with monthly & yearly totals, a customizable approval workflow, and an automated completeness checklist.

Overview

End-to-end TypeScript, two tiers over PostgreSQL, in a pnpm + Turborepo monorepo. The web SPA talks to a standalone, documented NestJS REST API; all money math lives in a pure, exhaustively tested estimation engine; the shared Zod contract is the single source of truth across the wire.
